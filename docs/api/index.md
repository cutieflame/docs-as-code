# API

API даёт доступ к функциям рекомендательной системы: сформировать
персональные рекомендации, получить последние рекомендации пользователя
и открыть карточку фильма.

## Основные операции

- `POST /recommendations`: сформировать рекомендации для пользователя;
- `GET /recommendations/{userId}`: получить последние рекомендации пользователя;
- `GET /movies/{movieId}`: получить карточку фильма.

## Пример запроса

```http
POST /api/v1/recommendations
Content-Type: application/json

{
  "userId": 42,
  "limit": 1
}
```

Ответ:

```json
[
  {
    "movie": {
      "id": 603,
      "title": "Матрица",
      "year": 1999
    },
    "score": 0.92,
    "modelVersion": "recsys-2.1"
  }
]
```

## Ошибки

| Код | Когда возникает |
|-----|-----------------|
| 400 | некорректный запрос, например нет `userId` |
| 404 | пользователь или фильм не найден |
| 503 | ML-модель временно недоступна |

## Спецификация

Полное описание API находится в файле [openapi.yaml](openapi.yaml).
Его можно открыть в [Swagger Editor](https://editor.swagger.io/).
