# Рекомендательная система фильмов

Рекомендательная система фильмов подбирает пользователю фильмы, которые ему
скорее всего понравятся. Внутри работает ML-модель, которая учится на оценках
пользователей: смотрит, что человек уже оценил высоко, и находит похожие фильмы
и людей с похожим вкусом.

Сервис экономит время: вместо того чтобы листать каталог, пользователь сразу
видит короткий список фильмов с объяснением, почему они ему подходят.

Основные пользователи:

- зритель (пользователь онлайн-кинотеатра);
- контент-менеджер, который следит за качеством рекомендаций;
- онлайн-кинотеатр, который получает рекомендации через API.

Основные функции:

- оценка просмотренных фильмов;
- получение персональных рекомендаций;
- просмотр карточки фильма.
